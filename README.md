# Recall for Interviews

An iOS-first study app for software engineers preparing for technical interviews in English. Practice recalling a concept, explain a trade-off, and revisit it on a schedule that responds to how you did.

**Status: planning.** No runnable app or store release yet. See the [product plan](docs/product-plan.md).

Example prompt: “When would a Layer 7 load balancer be a better choice than Layer 4? Name a trade-off.” Try answering before reading the explanation. The planned app will let you answer in writing or, in a later phase, record a spoken response.
