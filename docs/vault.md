# Local project knowledge

The Obsidian vault is private and lives outside this checkout. On the maintainer's workstation it is under `~/Documents/Obsidian Vault/Recall for Interviews`; override via `RECALL_VAULT` if needed. Use `scripts/recall-vault tree RFI-001` and `scripts/recall-vault search <terms>` for RECALL, then update the relevant private note via the CLI and run `scripts/recall-vault index && scripts/recall-vault check` for CAPTURE. The public product contract lives in `docs/product-plan.md`.
